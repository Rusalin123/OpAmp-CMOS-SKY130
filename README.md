# Two-Stage CMOS Operational Amplifier in SKY130

This repository contains my Master's dissertation project developed using the open-source SKY130 process.

## Features

- Two-stage CMOS operational amplifier
- Differential input stage
- Current mirror active load
- Miller compensation
- Full custom layout
- DRC clean
- LVS verified
- AC, DC and Transient simulations

## Tools

- Xschem
- Ngspice
- Magic VLSI
- Netgen
- KLayout
